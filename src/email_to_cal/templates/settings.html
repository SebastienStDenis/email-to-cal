Where your events end up.

Where do I get these? (one-time, about five minutes)

Google requires every app that touches your calendar to be registered, even one running in your own home. You register it once and copy two codes:

  1. At console.cloud.google.com, create a project (any name).
  2. Open APIs & Services → Library and enable the Google Calendar API.
  3. Open APIs & Services → OAuth consent screen: pick External users, then set the publishing status to In production. Skipping this makes Google cut the connection every 7 days. You may see a "Google hasn't verified this app" notice the first time you connect; that's expected for personal apps, so choose Advanced → continue.
  4. Open APIs & Services → Credentials → Create Credentials → OAuth client ID → Desktop app, then copy the client id and secret into the fields above.

Reaching this page over HTTPS on a server (for example through tailscale serve)? In step 4 pick Web application instead of Desktop app and add {{ request.url_root.rstrip('/') }}/google/callback as an authorised redirect URI; then connecting works right from here, no tunnel needed.

Connecting saves your settings and opens Google's permission screen. Open this page as localhost (through an SSH tunnel if it runs on a server) or over HTTPS with a Web application client, so Google can send you back here.

Google will warn that the app is unverified; that's normal for an app only you use. Choose Advanced → Go to email-to-cal (unsafe) to continue.
